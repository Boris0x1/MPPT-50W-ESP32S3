Diagramas de flujo de los algoritmos MPPT

Esta carpeta contiene los diagramas de flujo correspondientes a los algoritmos y mecanismos estudiados en la investigación sobre MPPT de un sistema fotovoltaico de 50 W.

El archivo `Diagramas_MPPT.pdf` reúne ocho diagramas:

1. P&O.
2. INC.
3. Meng original.
4. Meng V/I+.
5. Sondeo previo.
6. Combinación base.
7. Combinación+.
8. Variantes de ablación.

Los diagramas documentan la lógica de las estrategias numéricas y experimentales descritas en el artículo.

La campaña experimental principal comprende siete estrategias y 175 corridas. Los diagramas también documentan algoritmos y variantes adicionales estudiados en las simulaciones.

La correspondencia detallada con el firmware ESP32-S3 debe verificarse por separado.
